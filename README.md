# 食品化学复习站 · iPad 主屏幕版

放到 GitHub Pages（免费网页托管）上，用 iPad 的 Safari「添加到主屏幕」，就像一个 App：全屏显示、断网可用、进度存在 iPad 里。

## 第一次设置（约 10 分钟，用电脑操作）

1. 登录 github.com →「+」→「New repository」，名字填 `foodchem`，选 **Public**（免费的网页托管只支持公开仓库），点「Create repository」。
2. 点「uploading an existing file」，把这个文件夹里的**所有内容**拖进去（不是文件夹本身），点「Commit changes」。
3. 仓库上方「Settings」→ 左侧「Pages」→「Source」选「Deploy from a branch」→「Branch」选 `main`、文件夹选 `/ (root)` →「Save」。
4. 等 1–2 分钟刷新这个页面，顶部会出现网址：`https://你的用户名.github.io/foodchem/`。

## 装到 iPad 上

1. 在 iPad 的 **Safari** 打开上面的网址。
2. 点地址栏旁的「分享」按钮 →「添加到主屏幕」→「添加」。
3. **在联网状态下**从主屏幕点开这个图标，等侧栏底部显示「已可离线使用 · 进度保存在本机」（几秒钟）。
   主屏幕上的 App 和 Safari 是分开存储的，所以这一步要在主屏幕 App 里做一次。
4. 之后断网也能直接打开使用。

## 把网页版的进度搬过来

网页版「设置 → 生成备份 → 复制」→ 在主屏幕 App 的「设置」里粘贴到备份框 →「导入」。

## 以后更新

我更新复习站后会给你新文件，在仓库里覆盖上传即可。iPad 下次联网打开时会在后台下载新版本，**再打开一次**就是新版。进度不受影响。

## 注意

- 进度只存在这台 iPad 里，和网页版、安卓版不互通。
- 从主屏幕删除这个图标会清空进度。建议定期「设置 → 生成备份 → 复制」，存到备忘录里。
- 仓库是公开的，有链接的人都能看到网页内容；已经设置了不让搜索引擎收录。
